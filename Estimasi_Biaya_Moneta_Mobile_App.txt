dan memiliki Free Tier yang cukup untuk tahap awal.

  No.  Service                     Free Tier            Biaya Jika Melebihi
  ---  --------------------------  -------------------  --------------------
  1.   Firebase Authentication     50.000 user/bulan    Rp 0 (cukup)
  2.   Cloud Firestore (Database)  1 GB + 50K read/day  Mulai Rp 10.000/bln
  3.   Cloud Messaging (Notif)     GRATIS UNLIMITED     Rp 0
  4.   Firebase Hosting (Admin)    10 GB/bulan          Mulai Rp 5.000/bln
  5.   Firebase Storage (File)     5 GB gratis          Mulai Rp 4.000/bln
  6.   Firebase Analytics          GRATIS UNLIMITED     Rp 0
  7.   Firebase Crashlytics        GRATIS UNLIMITED     Rp 0

  Estimasi bulanan:
  - Skala kecil  (<1.000 user)   : Rp 0 (GRATIS)
  - Skala menengah (1.000-10.000): Rp 50.000 - 300.000/bulan

========================================================================
          PERBANDINGAN: WEB APP vs MOBILE APP
========================================================================

  Aspek              Web App               Mobile App (Flutter)
  -----------------  --------------------  -------------------------
  Hosting app        VPS/Vercel            Tidak perlu (dari store)
                     (Rp 0-300K/bln)
  Domain             Rp 100-200K/tahun     Tidak wajib
  SSL                Gratis                Tidak perlu (store)
  Store fee          Tidak ada             Play: Rp 400K (sekali)
                                           Apple: Rp 1.6jt/tahun
  Push notif         Perlu HTTPS + SW      FCM gratis unlimited
  Backend            Perlu VPS/serverless  Sama (Firebase recommended)
  Update             Deploy langsung       Review store 1-3 hari

  Kesimpulan: Biaya operasional mobile bisa LEBIH MURAH karena
  tidak perlu hosting/domain/VPS untuk app-nya sendiri.


========================================================================
          CATATAN PENTING
========================================================================

  1. Firebase memiliki Free Tier (Spark Plan) yang CUKUP untuk
     tahap awal, bahkan untuk ratusan pengguna.

  2. Baru perlu upgrade ke Blaze Plan (pay-as-you-go) jika
     jumlah pengguna sudah mencapai ribuan.

  3. Biaya di atas BELUM termasuk jasa development/developer.

  4. Maintenance bulanan (bug fix, update OS compatibility)
     biasanya berkisar 10-15% dari total biaya development
     per tahun.

  5. Kurs USD yang digunakan: 1 USD = Rp 16.000 (estimasi).
